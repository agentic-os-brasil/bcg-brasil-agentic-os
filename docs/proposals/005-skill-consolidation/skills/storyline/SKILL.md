# Storyline

The narrative craft, separated from slide production so it can be reused and improved on
its own. It answers "what is the argument and in what order", before `deck-builder` turns
it into pages.

## Method
1. **Governing thought first.** Lead with the answer; group the supporting arguments
   beneath it (MECE); evidence beneath those. Never bottom-up.
2. **SCQA when it helps.** Situation → Complication → Question → Answer, where a build-up
   serves the audience better than leading cold with the answer.
3. **Simplicity beats completeness.** The simplest arc that carries the real argument wins.
   Cut a branch that doesn't change the governing thought, even if it's true and interesting.
4. **The 30-second test.** Could the audience repeat the story back after hearing it once?
   If not, the storyline isn't done — slides won't fix it.

## Relations
- **Pulled by `deck-builder`** as its first step, so the storytelling method lives in one
  place.
- Also invocable by the **hub** directly when the user needs to sharpen a message or memo
  that isn't a deck.

# Grill Me

An interactive interrogation that surfaces *the user's own* thinking — the value is in
what they say under pressure, so you ask and they answer. This is a live, main-thread
conversation; it is not delegated to a sub-agent (a sub-agent cannot hold a back-and-forth
with the user).

## Method (high freedom — follow the weak answer, don't run a fixed script)
1. Lock the target in one line: what are we grilling, and what decision/output does it feed?
2. Ask ONE question, then stop and wait. Never answer your own question or race ahead.
3. Follow the weakest part of the answer with the next question. Cover, in whatever order
   the weak answers pull you: premise, the so-what, the load-bearing assumption, evidence,
   the hardest question the room will ask, the strongest opposing view, what they're avoiding.
4. Don't accept vague ("it should be fine" → "fine how? show me").
5. Stop when the thinking is materially sharper, or after ~3 waves.
6. Close: sharpened POV (1-2 lines) · what's still soft · the single hardest question to be
   ready for · the smallest next move.

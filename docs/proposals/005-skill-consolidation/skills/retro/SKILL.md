# Retro

A development ritual. The substance-gathering and the writing are `career-keeper`'s; the
live reflective conversation is the hub's (a sub-agent cannot hold it).

## Workflow
1. Call **`career-keeper`** in DIGEST mode: read this week's daily logs, `objectives.md`,
   and the last 1-2 retros, and return a compact evidence summary organized by objective
   (where it showed up, where it was missed, cross-week patterns).
2. **The hub walks the week WITH the user** using that digest — conversationally, bringing
   receipts, asking before concluding. Land on ONE concrete, observable intention for next
   week.
3. Call **`career-keeper`** in WRITE mode to write the retro file and add strong moments to
   the evidence log in `objectives.md`; promote any durable learning through the
   **`record-learning`** skill.

## Relations
- **Orchestration + interactive.** Calls `career-keeper` (DIGEST then WRITE) and
  `record-learning`; the hub holds the conversation in between. Feeds the same evidence
  that a career conversation later compiles.

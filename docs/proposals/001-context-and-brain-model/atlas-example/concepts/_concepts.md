# 🧠 Concepts — index

> Mother file (MOC) for `atlas/concepts/`. Reusable methods, frameworks, and playbooks that
> outlive any single case — the hard, technical craft an associate builds toward partner.
> Deliberately the *technical* counterpart to [`learnings/`](../learnings/_learnings.md)'s
> *soft* register.
> Up: [Proposal 001 — Context and Brain Model](../../001-context-and-brain-model.md), §4.

> Start here when the question is *"how do we do X / do we already have a way to do this?"*
> — before reinventing or searching externally.

## How it links
Plain relative Markdown links. Every reusable asset gets (a) one line here and (b) a
`## Related` footer linking back.

## Members
_(one line per method/framework, grouped by theme, with "when to use it" — e.g.:)_
- **[Spend cube / value quantification](spend-cube-value-quantification.md)** — always run
  in this order, with this framework. *When:* any spend-cube / ABC-curve / future-spend
  workstream.

## How to add
1. Built a method/framework/playbook you'll reuse? Give it a file
   (`atlas/concepts/<slug>.md`).
2. Add **one line** above, with the *when to use it*.
3. Add a `## Related` footer in the new file, linking back here and to neighbouring assets.

# 👤 People — index

> Mother file (MOC) for `atlas/people/`. Profiles of internal colleagues (project leaders,
> managers, partners, peers) — analogous to `atlas/clients/` but for the people you work
> *with* inside the firm, not the client side. Not in the original proposal draft; added after
> finding it already real and in active use in Maestro's `brain/people/`.
> Up: [Proposal 001 — Context and Brain Model](../../001-context-and-brain-model.md), §4.

## Why this exists
`atlas/clients/` captures the client side. This folder captures who you work *with*
internally: leadership style, how they give/receive feedback, cases done together,
communication preferences — so you don't relearn the same patterns on every new project.

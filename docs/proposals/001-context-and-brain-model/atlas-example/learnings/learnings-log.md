# Learnings Log

> The running, append-only record of career-spanning wisdom — not a case decision, not a
> technical method. Newest entry at the top. Never rewritten; if a later experience
> complicates or overturns an old entry, add a new one and note the tension rather than
> deleting the old one — the contradiction is itself part of the learning.
> ↑ Mother: [`_learnings.md`](_learnings.md)

## Entry shape
```
### YYYY-MM-DD · <one-line learning>
- **What happened:** _(the moment/pattern that surfaced this)_
- **The learning:** _(stated so it still makes sense years from now, without the specific case)_
- **Related:** _(a project, a person, a concept — if there's a natural link)_
```

## Extensões solicitadas nesta consolidação

- Codex: AGENTS.md, skills nativas copiadas sem symlinks, agentes TOML e hooks com binding explícito da raiz confiável; uma pasta aninhada não escolhe o launcher.
- caseOS: instalação MCP guiada, consentimento por workspace/caso, URL oficial completa sem path inventado, descoberta atual e binding de parâmetro de caso pertencente à política por ferramenta. Sem exportação automática.
- Update: kits separados Mac/Windows ou combinado, contrato JSON v2, checkpoints/retomada e Yoda real. O kit não contém dados pessoais nem obriga o host a ultrapassar limites.

## Evidência e limites

Resultados e hashes dos kits: [evidência local do candidato](0.2.0-local-evidence.md).

A suite Go completa passou na rodada de integração, assim como regressões locais de migração, guard, contexto, privacidade e contratos. PowerShell 7 em macOS executou 65 checks com helper Darwin real e PATH vazio nos hooks; isso não prova Windows nativo. Consulte os relatórios de execução e rerode os gates no commit final.

O baseline 0.1.11 usado nos testes de pacote é reconstruído do source, não o ZIP original enviado ao campo. O baseline 0.1.12 é um candidato arquivado, sem inferência de distribuição. Windows 5.1/7 nativo, CI hospedada, sessão real dos hosts e caseOS autenticado exigem evidência própria. Assinatura/notarização corporativas e publicação não são herdadas de hashes locais.

## Achados Gamma tratados

1. Launcher Codex aninhado: binding absoluto, quoting por plataforma, configuração alheia preservada e regressão de wrapper real.
2. Topologia insegura pós-commit: scan completo antes de tolerar edição regular; symlinks/tipos/IO bloqueiam sem sobrescrever autoridade terminal, com recuperação após reparo.
3. Substituição de case parameter: mapeamento tool→campo autorizado na política; request não escolhe a autoridade do escopo.

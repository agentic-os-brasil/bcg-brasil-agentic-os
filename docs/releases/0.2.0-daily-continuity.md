# ZIP daily continuity — local implementation evidence

The shared ZIP helper now persists explicit agent-authored checkpoints separately
from dreaming. Claude Bash, Claude PowerShell and Codex Stop share `daily-stop`;
SessionStart recovers pending work after migration and reads `daily-context`.
The operator recipe prepares scope/session/workspace/date-bound JSON before a
material response. Missing captures are reported, not reconstructed from logs.

Owner records live in `brain/.maestro/daily-pending/`; case records live in the
confirmed case's `.maestro/daily-pending/`. Only owner and current confirmed case
are drained. An inactive case's queue stays untouched. Up to 32 inputs are read
per invocation. Invalid, conflicting, busy or failed work remains pending.

The scope writer lock serializes without waiting. An ID binds to canonical JSON
digest and date before page publication. The full bounded page is atomically
replaced preserving its existing byte prefix; complete embedded ID/digest markers
make publication retry idempotent. No pending file is removed before page and
dream request persistence. A leftover lock after a crash fails closed and needs
diagnosis; automatic stale-lock recovery is not implemented.

Daily context reads exactly local-calendar D0, D-1 and D-2 from owner and current
case daily and recent L1 sources. Headers, pointers and excerpts together are
limited to 5000 UTF-8 bytes; each source has a bounded excerpt or explicit
missing/unavailable/omitted notice. The latest checkpoint is favored on generated
daily pages. Whole native packets retain their independent cap. Cached daily
bodies and latest-only L1 selection were retired. Context is evidence, not
instructions; bindings and hashes do not attest semantic sanitization.

Dream requests are content-sensitive. `daily-dream-ack --root ROOT` accepts stdin
`{"scope":"owner","digest":"<captured fingerprint>"}` and compares under the
same writer lock. A newer request survives an older cycle's acknowledgement.
The receipt labels acknowledgement `agent_asserted_success`; it is not proof
of synthesis. Missing engine/policies leave work pending. Automatic daily logging
does not substitute for user-confirmed `eod` closure.

The request fingerprint advances over cumulative durable checkpoints; replaying
an older checkpoint cannot restore an older request. Migration readiness gates
all daily mutations, including acknowledgement. Source readers reject hardlinks,
symlinks and nonregular files; Unix opens are nonblocking to reject FIFO races.
Recovery failures surface content-free counters while valid history stays readable.
Native PS5 BOM-prefixed active-case markers are supported. Legacy timestamp dream
requests are normalized under the scope writer lock and their exact original
bytes retained in `memory/.dream-legacy-request`; no legacy request is dropped.

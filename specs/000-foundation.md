# Spec 000 - Foundation

Status: accepted for repository bootstrap.

## Objective

Create the smallest credible foundation for a professional BCG Brasil Agentic OS that can evolve without mixing distribution code, user state and client work.

## Must have

- Private canonical source repository.
- Clear professional-only scope.
- CLI-first product direction.
- Versioned release and bundle model.
- Explicit managed-core versus local-data boundary.
- Progressive roadmap and honest implementation status.

## Must not have

- Personal-domain content.
- Real client or employee data.
- Credentials, tokens or secrets.
- Copied Kowalski identity or taxonomy.
- Claims that unimplemented capabilities already work.
- Premature marketplace, daemon, telemetry or background updater.

## Initial success condition

A new contributor can understand the intended product, decisions, boundaries and next implementation step from the repository alone.

Quero verificar a atualização do Maestro para a versão {{TO_VERSION}}.

Faça uma verificação local completa, sem alterar meu conteúdo:

1. confirme que VERSION é exatamente {{TO_VERSION}};
2. confirme que data/ e ../Maestro-old-{{FROM_VERSION}}/data/ existem. Compare
   diretamente as duas árvores, em modo somente leitura, com
   `diff -qr -- data ../Maestro-old-{{FROM_VERSION}}/data`. Só marque PASS se
   não houver diferença; qualquer diferença é FAIL, pasta antiga ausente é
   UNAVAILABLE e uma contagem igual de arquivos não basta;
3. execute maestro-doctor e reporte separadamente Bash, Python 3 e os hooks;
4. confira em .claude/settings.json o wiring de SessionStart,
   UserPromptSubmit, PreToolUse para escrita, PreToolUse para Agent/Task e Stop;
5. confirme que as projeções .claude/agents e a política de ativação existem;
6. faça um canário real: use a ferramenta Agent com subagent_type `yoda` para
   revisar, em uma frase, se esta atualização foi validada com evidência
   suficiente. Não simule a resposta e não substitua a chamada por uma leitura
   do arquivo do agente;
7. confirme se o anúncio de ativação chegou ao contexto e se houve retorno real
   do Agent.

No final, reporte cada item como PASS, FAIL ou UNAVAILABLE. Diferencie arquivo
configurado, hook executado e Agent realmente chamado. Se Bash ou Python 3
faltarem, ou se o Agent não for chamado, não diga que a atualização está
concluída.

# caseOS: aprender e consultar

Leia [o guia](references/guide.md) e explique apenas o necessário para o pedido.
Ensine entidades, observações, relações e tarefas com exemplo sintético,
distinguindo conceito de schema disponível. Tutorial não exige login.

Para consultar dados reais, carregue [caseos-connect](../caseos-connect/SKILL.md):
ele é a autoridade única de conexão, consentimento e seleção de ferramentas.
Use descoberta atual, nunca traduza nomes de ferramentas de outro host por palpite.
Comece pela pergunta e pelo caso confirmado; busque o assunto, leia os registros
relevantes e só depois explore conexões que ajudem a respondê-la. Não faça um
inventário completo por reflexo. Retorne resposta, fonte, data e lacunas.
Uma página parcial ou busca por relevância não prova ausência nem completude.

Sem conexão, ensine com exemplos e dados locais autorizados, identificados como
tais; não invente uma consulta. Para novo material, encaminhe a
[caseos-prepare-ingest](../caseos-prepare-ingest/SKILL.md); para melhorar um recorte
existente, a [caseos-prepare-enrichment](../caseos-prepare-enrichment/SKILL.md).
Ambas preparam propostas locais, não publicam.

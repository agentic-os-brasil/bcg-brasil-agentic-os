# Retro

Resolve the canonical `interaction-profile` before responding. It changes tone
and depth only; it never reads private history or writes development records.

## Orchestration contract

- Accept only a current-request recap, objectives and optional evidence.
- Use `record-learning` to frame a durable lesson candidate when useful.
- Return observed patterns, one retained strength, one improvement intention and
unresolved evidence gaps.
- Do not infer sensitive traits, read old retros, create a private record or
present a reflection as clinical or authoritative assessment.

## Completion

Return a human-reviewed reflection. Owner-private persistence is unavailable
until a dedicated capability provides consent, provenance and reversal.

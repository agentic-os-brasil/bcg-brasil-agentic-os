# Record Concept

Resolve the canonical `interaction-profile` before responding. It changes
presentation only; it never writes a concept, index or practice canon.

## Contract

- Accept only the method, evidence of reuse and examples supplied in the
  current request.
- Return purpose, use conditions, steps, limitations, evidence and a promotion
  recommendation.
- Mark an unproven one-off as a candidate rather than a reusable standard.
- Do not create a file, update an index, infer practice approval or disclose
case material.

## Completion

Return a concept candidate for review. Canonical promotion and owner-private
storage remain separately governed.
